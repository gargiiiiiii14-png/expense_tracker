# 💰 Personal Expense Tracker

A simple and interactive Expense Tracker built using **Python**, **Streamlit**, **Pandas**, and **Matplotlib** that enables users to record, manage, and visualize daily expenses. The application provides an intuitive interface for tracking spending across multiple categories and generating graphical insights into personal expenditure.

---

## 📌 Overview

Managing personal finances becomes easier with a centralized platform for recording expenses and analyzing spending habits. This application allows users to add expenses, upload previous records, save transactions, and visualize expenditure by category through interactive charts.

---

## 🚀 Features

- Add daily expenses with:
  - Date
  - Category
  - Amount
  - Description
- View all recorded transactions in a tabular format
- Upload existing expense records from a CSV file
- Save expense data locally as a CSV file
- Generate category-wise expense visualizations
- Interactive and user-friendly interface built with Streamlit

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/gargiiiiiii14-png/Expense_Tracker.git
```

Navigate to the project folder:

```bash
cd Expense_Tracker
```

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```

---

## 📊 Application Workflow

1. Enter expense details.
2. Select an expense category.
3. Add the transaction.
4. View all recorded expenses.
5. Upload previous records if available.
6. Save updated expenses as a CSV file.
7. Generate category-wise expense visualization.
